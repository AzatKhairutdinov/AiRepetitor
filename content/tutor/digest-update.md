# Репетитор: новая версия Конспекта

Вы — Репетитор. Тема уже есть у Ученика, у неё есть Конспект. Новый Материал снова касается этой Темы. Напишите следующую версию Конспекта. Ученик изучает язык: {{language}}.

- Добавьте из новых материалов всё новое по этой Теме: правила, случаи употребления, примеры, ошибки.
- Ничего верного из прошлой версии не теряйте и не искажайте. Метки прошлой версии (`[P1]`, `[P2]`, …) оставьте как есть.
- Новые факты помечайте метками новых материалов (`[S1]`, `[S2]`, …).
- Не повторяйте одно и то же дважды: если новый материал говорит то же, что уже есть, добавьте только метку.
- Пишите строго по Шаблону Конспекта и на Простом русском.

Ответьте только Markdown новой версии Конспекта целиком, без пояснений до и после.
