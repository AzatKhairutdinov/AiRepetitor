# Интент для сессии grill-with-docs

Скопируйте блок ниже в новую сессию после `/grill-with-docs`.

```text
Проверь на прочность первую доменную модель AI-репетитора.

Прочитай сначала: GLOSSARY.md, docs/domain/model.md, docs/adr/.

Что уже есть. Ученик загружает Материал: один или несколько Исходников
(документы, таблицы, PDF, картинки, аудио, видео, ссылки на YouTube).
Система достаёт Текст исходника. Репетитор пишет Конспекты по Шаблону
простым русским языком. По Конспекту Репетитор собирает Тренировку
из Упражнений разных видов (диалог, пересказ, вопросы к тексту,
раскрой скобки) на Опорных текстах. Методист (тоже AI) проверяет
Конспект по исходникам, а Тренировку по Конспекту. Репетитор
исправляет по Отчёту о проверке. Кругов правки по умолчанию 1, и Ученик
видит итог в любом случае.
Экран — Карточка материала: слева меню материалов, в центре Чат
с Репетитором, рядом исходники, конспекты, тренировки.

Решения из раздела «Решения» в docs/domain/model.md не пересматривай.

Цель сессии: закрыть открытые вопросы из docs/domain/model.md и
решить, что входит в первую фичу «Загрузить материал».

Допрашивай меня по одному вопросу за раз. Начни с самых дорогих
для изменения:
1. Только языки или любой предмет?
2. Конспект на материал или на исходник?
3. Границы Материала: можно ли добавлять и удалять исходники потом?
4. Как устроены Шаблон, Простой русский и Проверки, чтобы их можно было
   быстро менять и сравнивать версии? Нужен ли ADR?
5. Что входит в простые проверки кодом, а что оценивает Методист.
6. Что Ученик может делать в Чате.
7. Минимальный набор видов упражнений и как Репетитор оценивает Ответ.

Придумывай сценарии на грани: материал на двух языках, видео на 3 часа,
скриншот с рукописью, исходник не удалось прочитать, ученик загрузил
одно и то же дважды, опорный текст из интернета с авторскими правами.

Обновляй GLOSSARY.md сразу, как термин решён. ADR предлагай только для
решений, которые дорого менять. В конце сформулируй первые issues
в GitHub для фичи «Загрузить материал».
```
